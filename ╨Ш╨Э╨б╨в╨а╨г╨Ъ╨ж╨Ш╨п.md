# Инструкция: проверка и загрузка на GitHub

## 1. Проверьте проект локально

Нужен Node.js 21 или новее (`node --version`).

```bash
cd habit-heatmap

# Запустите приложение и откройте http://localhost:8080
npm start
# Демо-режим: http://localhost:8080/?demo

# В другом терминале запустите модульные тесты (без установки зависимостей)
npm test

# Браузерные тесты (один раз установите Playwright)
npm install
npx playwright install chromium
npm run test:e2e
```

Что стоит проверить руками:

1. Добавьте пару привычек и отметьте их на сегодня: должна появиться серия 🔥 и закраситься сегодняшняя клетка.
2. Кликните по названию привычки, а затем по клеткам прошлых дней на карте: отметки должны ставиться и сниматься, а статистика пересчитываться.
3. Перезагрузите страницу: данные должны остаться.
4. Удалите привычку и нажмите «Отменить» в уведомлении внизу: она вернётся вместе с историей. Нажмите «Экспорт», удалите привычку и импортируйте сохранённый файл: всё должно восстановиться.
5. Переименуйте привычку кнопкой ✎ (Enter сохраняет, Esc отменяет).
6. Переключите тему и сузьте окно до ширины телефона.

> Если открыть `index.html` двойным кликом, страница будет пустой: браузер не загружает модули по `file://`. Используйте `npm start` или `python -m http.server 8080`.

## 2. Создайте репозиторий на GitHub

1. Откройте https://github.com/new.
2. Repository name: `habit-heatmap`.
3. Description: `Трекер привычек с тепловой картой в стиле GitHub — чистый JS, офлайн, с тестами`.
4. Выберите Public. **Не** добавляйте README, .gitignore и лицензию: они уже есть в проекте.
5. Нажмите Create repository.

## 3. Загрузите код

Замените `<ник>` на ваш логин GitHub:

```bash
cd habit-heatmap
git init
git add .
git commit -m "Habit Heatmap: трекер привычек с тепловой картой"
git branch -M main
git remote add origin https://github.com/<ник>/habit-heatmap.git
git push -u origin main
```

Папка `node_modules/` исключена через `.gitignore`, поэтому в репозиторий она не попадёт.

## 4. Необязательно: опубликуйте на GitHub Pages

Приложение статическое, поэтому его можно бесплатно выложить на GitHub Pages:

1. В репозитории откройте **Settings → Pages**.
2. В разделе Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите Save.
3. Через минуту приложение будет доступно по адресу `https://<ник>.github.io/habit-heatmap/`. Добавьте эту ссылку в описание репозитория (поле Website) и в README.

Для портфолио также стоит добавить в репозитории темы (Topics): `javascript`, `habit-tracker`, `heatmap`, `vanilla-js`, `localstorage`.
