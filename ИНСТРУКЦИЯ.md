# Инструкция: проверка и обновление репозитория (версия 2.0.0)

Это доработка существующего проекта https://github.com/mrsolo743-dot/habit-heatmap. Новый репозиторий создавать не нужно: изменения добавляются одним коммитом в ветку `main`.

## 1. Проверьте проект локально

Нужен Node.js 21 или новее (`node --version`).

```bash
cd habit-heatmap
npm start                      # http://localhost:8080, демо: http://localhost:8080/?demo

# в другом терминале
npm test                       # 63 модульных теста, без установки зависимостей
npm install                    # один раз, для браузерных тестов
npx playwright install chromium
npm run test:e2e               # 20 сквозных тестов
```

Что посмотреть руками (удобнее всего на `?demo`):

1. **Цели.** У демо-привычек разные цели: «Читать» каждый день, «Зарядка» 4 раза в неделю, «Английский» 3 раза. В списке рядом с названием виден прогресс недели (`3/4`); когда цель выполнена, значок закрашивается.
2. **Панель привычки.** Кликните по названию «Зарядка». Под статистикой появится блок «Цель на неделю»: кружки прогресса, подсказка «осталось N раз за M дней», серия и рекорд недель, доля успешных недель. Поменяйте цель в выпадающем списке: всё пересчитается и сохранится после перезагрузки.
3. **Предупреждение.** Откройте `?today=2026-11-08` (воскресенье), добавьте привычку с целью 3 раза и отметьте один день: появится красная надпись «уже не успеть».
4. **Годы.** В правом верхнем углу карты выберите «2025 год»: карта покажет календарный год с января по декабрь, а графики «По месяцам» и «По дням недели» пересчитаются за этот год. Наведите курсор на столбик, чтобы увидеть точные цифры.
5. **Миграция.** Если у вас в браузере остались данные от версии 1 (вы пользовались приложением раньше), они подхватятся сами, а у всех привычек будет цель «каждый день». Старый файл экспорта тоже можно импортировать.
6. Сузьте окно до ширины телефона: форма и графики перестраиваются, карта календарного года прокручивается внутри панели.

## 3. Загрузите изменения на GitHub

### Способ А: патч (рекомендуется)

В архиве рядом с папкой проекта лежит `habit-heatmap-v2.patch`. Это готовый коммит с сообщением и всеми изменениями, включая переименование файлов.

```bash
cd Desktop/Projects
git clone https://github.com/mrsolo743-dot/habit-heatmap.git   # если репозитория ещё нет на компьютере
cd habit-heatmap
git checkout main
git pull
git am ../habit-heatmap-v2.patch      # путь к патчу из архива
git commit --amend --reset-author --no-edit   # автором коммита станете вы (ваши user.name/user.email из git)
git log --oneline -3                  # сверху должен быть коммит v2.0.0
git push origin main
```

Если `git am` сообщит о конфликте (значит, в репозитории после 6 ноября что-то менялось), выполните `git am --abort` и используйте способ Б.

### Способ Б: замена файлов

```bash
cd Desktop/Projects/habit-heatmap
git pull
git rm -r -q .            # убирает старые файлы из рабочей папки (история в git сохраняется)
# скопируйте сюда всё содержимое папки habit-heatmap из архива, включая .gitignore
git add -A
git status                # проверьте: два .md переименованы, новые файлы добавлены
git commit -m "v2.0.0: цели на неделю, статистика по месяцам и дням недели, переключатель года"
git push origin main
```
